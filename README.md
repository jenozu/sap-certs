# ERP Business Process Automation Developer — Learning Hub

This repository is the central reference for my transition into **ERP application development, business-process automation and systems integration**.

The goal is to learn how to understand business workflows, build applications that remove repetitive work, connect ERP platforms to external systems, and demonstrate those skills through practical portfolio projects.

> **Career direction:** ERP Business Process Automation Developer / ERP Application Developer, with an initial SAP specialization and transferable skills for other ERP platforms.

## Learning order

**SQL → JavaScript → TypeScript → Node.js → SAP CAP → SAP Integration Suite / SAP Build → Python**

Python intentionally comes later. JavaScript/TypeScript and Node.js are the primary development foundation for the SAP CAP path. Python is added later for document processing, data work and AI-assisted automation.

## Guiding principles

- Learn by building, not by collecting certificates.
- Apply for relevant roles before completing the entire roadmap.
- Prefer practical interactive lessons and projects over long theory-only courses.
- Use synthetic data in public repositories. Never publish employer data, customer details, credentials or confidential workflows.
- Build integrations using supported APIs and documented interfaces; avoid fragile screen-click automation when a proper API is available.
- Treat financial, inventory and purchasing updates carefully: validate inputs, prevent duplicates, log actions, handle errors and require human approval where appropriate.
- Measure project outcomes honestly. Clearly label estimates and distinguish them from measured results.
