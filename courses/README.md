# Course Curriculum

This is the selected learning sequence for the ERP Business Process Automation Developer path. The aim is practical competence, not collecting every available course.

## Sequence

| Order | Course / learning resource | When |
|---|---|---|
| 1 | [Codecademy — Intro to SQL](https://www.codecademy.com/learn/intro-to-sql) | Completed |
| 2 | [Codecademy — Learn SQL](https://www.codecademy.com/learn/learn-sql) | Now |
| 3 | [Codecademy — Design Databases With PostgreSQL](https://www.codecademy.com/learn/paths/design-databases-with-postgresql) | After Learn SQL |
| 4 | [Codecademy — Learn JavaScript](https://www.codecademy.com/learn/introduction-to-javascript) | After SQL project |
| 5 | [Codecademy — Learn Intermediate JavaScript](https://www.codecademy.com/learn/learn-intermediate-javascript) | After JavaScript basics |
| 6 | [Codecademy — Learn TypeScript](https://www.codecademy.com/learn/learn-typescript) | After JavaScript |
| 7 | [Codecademy — Learn Intermediate TypeScript](https://www.codecademy.com/learn/learn-intermediate-typescript) | Recommended follow-on |
| 8 | [Codecademy — Learn Node.js: Fundamentals](https://www.codecademy.com/learn/learn-nodejs-fundamentals) | After TypeScript foundations |
| 9 | [Codecademy — Learn Node.js](https://www.codecademy.com/learn/learn-node-js) | Next |
| 10 | [Codecademy — Learn Express](https://www.codecademy.com/learn/learn-express) | Next |
| 11 | [SAP Learning — Introduction to SAP CAP](https://learning.sap.com/courses/introduction-to-sap-cloud-application-programming-model) | After Node.js |
| 12 | [SAP Developers — CAP Node.js](https://developers.sap.com/concepts/cap-nodejs-development/) | Alongside CAP practice |
| 13 | SAP Integration Suite and SAP Build learning | After first CAP application |
| 14 | [Codecademy — Learn Python 3](https://www.codecademy.com/learn/learn-python-3) | Later, after the JS/Node/CAP sequence |

Course URLs, names, availability, prices and lesson structures can change. Check the provider's page before enrolling.

## What not to do

- Do not take multiple overlapping SQL courses just to accumulate certificates.
- Do not move Python ahead of JavaScript, TypeScript, Node.js and CAP.
- Do not start with ABAP or deep BTP administration.
- Do not delay applications until every course is complete.
- Do not treat finishing a course as proof of mastery; complete exercises and build projects.
