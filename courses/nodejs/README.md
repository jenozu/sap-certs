## Skills to acquire

- Node.js runtime and npm.
- Modules and package management.
- HTTP fundamentals.
- REST API design and consumption.
- JSON request/response bodies.
- Express routes and middleware.
- Environment variables and secret handling.
- Authentication basics.
- Database connections and parameterized queries.
- Input validation.
- Error handling, logging and testing.
- Webhooks and event-driven workflows.
- Preventing duplicate processing and making operations safe to retry.

## Project milestone

Build a Shipping Automation System with a simulated ERP API and simulated carrier API. Retrieve an order, validate the ship-to details, submit a shipment request, record tracking data, prevent duplicate shipment creation and log outcomes.

Use synthetic data and document how the system would connect to a real ERP through supported APIs.
