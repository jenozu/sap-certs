# TypeScript Learning Plan

**Status:** Upcoming — after JavaScript foundations.

## Courses

1. [Codecademy — Learn TypeScript](https://www.codecademy.com/learn/learn-typescript)
2. [Codecademy — Learn Intermediate TypeScript](https://www.codecademy.com/learn/learn-intermediate-typescript) — recommended follow-on.
3. [Total TypeScript tutorials](https://www.totaltypescript.com/tutorials) — reference and extra practice.

## Skills to acquire

- Type annotations and inference.
- Primitive, array, object and function types.
- Type aliases and interfaces.
- Union and intersection types.
- Optional properties and optional parameters.
- Literal types and narrowing.
- Generics at a practical introductory level.
- Modules and imports/exports.
- Typing API responses and application data.
- Understanding compiler errors and strict type checking.

## Project milestone

Convert or rebuild the inventory application with TypeScript. Define reliable types for products, suppliers, purchase orders, stock movements and API responses.
