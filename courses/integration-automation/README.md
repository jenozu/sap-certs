# SAP Integration Suite and SAP Build

**Status:** Upcoming — after the first CAP application.

## SAP Integration Suite

Learn how to connect SAP and non-SAP systems using supported interfaces.

Topics:
- Integration flows (iFlows).
- API management and REST APIs.
- Data mapping and transformations.
- Authentication and secure connectivity.
- Error handling, retries and monitoring.
- Event-driven integration concepts.

## SAP Build Process Automation

Learn how to model business workflows, approvals, forms and notifications. Use low-code capabilities where they are a sensible fit; use CAP or other code-based services for complex business logic.

Topics:
- Workflow design.
- Approvals and human tasks.
- Forms and business rules.
- Notifications.
- Process monitoring and exception paths.
- Calling APIs and integrating with applications.

## Project milestone: Direct-Ship Automation

Build a workflow around the principle **"enter it once, SAP follows."**

A request should be validated, relevant purchasing/shipping information prepared, external systems connected, progress tracked and duplicate processing prevented. Financial or inventory-changing actions should have explicit authorization and an audit trail.

The first version can use mock APIs. The goal is to demonstrate the architecture and business logic without needing production SAP access.
