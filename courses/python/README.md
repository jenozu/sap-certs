# Python, Data Processing and AI

**Status:** Later — after JavaScript, TypeScript, Node.js and SAP CAP foundations.

Python is not the primary language for the initial SAP CAP path. Learn it later to add document processing, data workflows and AI-assisted capabilities to applications.

## Course

- [Codecademy — Learn Python 3](https://www.codecademy.com/learn/learn-python-3)
- [Exercism Python](https://exercism.org/tracks/python)
- [Kaggle Learn Python](https://www.kaggle.com/learn/python)

## Skills to acquire

- Python fundamentals, functions, collections and modules.
- Reading and writing CSV, Excel and PDF files.
- Data processing with pandas.
- Calling APIs and handling JSON.
- Document extraction and validation.
- AI/LLM API integration.
- Logging, error handling and testing.

## Project milestone: AI-Assisted Invoice Processing

Extract invoice fields from synthetic supplier documents, validate them, match them to purchase orders and goods receipts, flag exceptions and prepare an approval package. AI may assist with extraction, but deterministic business rules should validate the results.
