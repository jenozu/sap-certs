# SQL Learning Plan

**Status:** In progress  
**Completed:** Codecademy Intro to SQL  
**Next:** Codecademy Learn SQL

## Selected courses

1. [Codecademy — Intro to SQL](https://www.codecademy.com/learn/intro-to-sql) — completed; introductory exposure to querying and manipulating data.
2. [Codecademy — Learn SQL](https://www.codecademy.com/learn/learn-sql) — complete the lessons on queries, aggregate functions and multiple tables.
3. [Codecademy — Design Databases With PostgreSQL](https://www.codecademy.com/learn/paths/design-databases-with-postgresql) — learn relational database design, PostgreSQL, normalization and indexes.

These courses are intended to provide a practical foundation. They do not need to make me an SQL expert.

## SQL topics to be comfortable with

See the [SQL Foundation Checklist](foundation-checklist.md) for the complete topic list and graduation criteria.

Core skills:
- SELECT, FROM, aliases, DISTINCT, ORDER BY and LIMIT.
- WHERE, AND, OR, IN, BETWEEN, LIKE and NULL checks.
- COUNT, SUM, AVG, MIN, MAX, GROUP BY and HAVING.
- INNER JOIN and LEFT JOIN; primary and foreign keys.
- INSERT, UPDATE and DELETE, used safely.
- Table creation, data types, constraints and relationships.
- Basic subqueries, CASE, CTEs and UNION.
- Basic indexes and transactions (BEGIN, COMMIT, ROLLBACK).

## Practice environment

Use SQLite for quick local practice and PostgreSQL during the database-design course. SQL is the language; SQLite and PostgreSQL are database systems that implement it with some dialect differences.

Useful extra practice:
- [SQLBolt](https://sqlbolt.com/)
- [SQLZoo](https://sqlzoo.net/)
- [HackerRank SQL](https://www.hackerrank.com/domains/sql)

These are optional practice resources, not additional mandatory courses.

Build the [Distribution Operations Database](../../projects/sql-distribution-database/README.md), using synthetic data. Record a short screen walkthrough and publish the code, schema, sample data, diagrams and explanation in the project repository.
