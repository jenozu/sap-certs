## Skills to acquire

- Variables, values, operators and expressions.
- Strings, numbers, booleans, arrays and objects.
- Conditions, loops and functions.
- Scope and basic modules.
- Array methods such as map, filter, find, reduce and forEach.
- Object and array manipulation.
- Error handling with try/catch.
- JSON parsing and serialization.
- Asynchronous programming, promises and async/await.
- HTTP requests and using APIs.
- Basic testing and debugging.
- Git branches, commits, pushes and pull requests.

## Project milestone

Build an Inventory Lookup and Reporting Application using the SQL database from the previous stage. Users should be able to search products, inspect supplier and purchasing information, view stock and generate simple reports.

Do not just follow a tutorial line by line. Be able to explain the code and make a small change without copying.
