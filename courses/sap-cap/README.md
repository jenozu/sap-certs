# SAP CAP Learning Plan

**Status:** Upcoming — after Node.js and API foundations.

## Learning resources

- [SAP Learning — Introduction to SAP Cloud Application Programming Model](https://learning.sap.com/courses/introduction-to-sap-cloud-application-programming-model)
- [SAP Developers — CAP Node.js development](https://developers.sap.com/concepts/cap-nodejs-development/)

## Skills to acquire

- CAP architecture and project structure.
- CDS data modelling.
- Entities, associations and compositions.
- Services and projections.
- OData service exposure and consumption.
- Node.js business logic and event handlers.
- Validation and authorization.
- Connecting to databases and external services.
- Testing, deployment concepts and application configuration.
- SAP BTP fundamentals needed to run and operate the application (not deep platform administration).

## Project milestone

Build a Procurement and Invoice Comparator. Model purchase orders, goods receipts and supplier invoices; compare quantities and prices; produce exception records; and require an authorized human approval before any consequential update.

Start with local or synthetic data. Connect to an SAP system only when an authorized test environment and supported API access are available.
