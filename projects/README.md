# Portfolio Projects

Projects should grow alongside the learning roadmap. Each one should solve a recognizable business problem and demonstrate the skills learned at that stage.

## Project sequence

| # | Project | Main skills | Purpose |
|---|---|---|---|
| 1 | [Distribution Operations Database](sql-distribution-database/README.md) | SQL, relational design | Model inventory, suppliers, purchasing, receiving and invoices; create useful reports |
| 2 | Inventory Lookup and Reporting Application | JavaScript, SQL | Search and report on operational data |
| 3 | Shipping Automation System | TypeScript, Node.js, REST APIs | Validate orders and coordinate shipment creation |
| 4 | Procurement / PO-GRPO-Invoice Comparator | SAP CAP, CDS, OData | Compare documents and flag quantity/price discrepancies |
| 5 | Direct-Ship Automation | Integration Suite, SAP Build, CAP | Coordinate a multi-system business workflow |
| 6 | AI-Assisted Invoice Processing | Python, document extraction, AI | Extract, validate and reconcile supplier invoice data |

## Project rules

- Use fictional company names and synthetic records.
- Do not publish Marindustrial customer/supplier data, documents, credentials, screenshots or confidential business rules.
- Include a clear business problem and intended user.
- Keep scope small enough to finish a working version.
- Include tests and sample data.
- Explain assumptions and limitations.
- Record a short walkthrough.
- Make a clear distinction between measured results and illustrative estimates.

See [Portfolio Standard](../portfolio/README.md) for the required presentation format.
