# Weekly Study Schedule

Target: **15 hours per week**. Keep the routine consistent; change the learning material as each roadmap stage is completed.

| Day | Focus | Time |
|---|---|---:|
| Monday | SAP / enterprise application learning | 2 hours |
| Tuesday | Current programming course | 2 hours |
| Wednesday | SAP / enterprise application learning | 2 hours |
| Thursday | Current programming course | 2 hours |
| Friday | SAP / enterprise application learning | 2 hours |
| Saturday | Portfolio project build | 3 hours |
| Sunday | Portfolio project, review and notes | 2 hours |
| **Total** | | **15 hours** |

During the SQL stage, Tuesday and Thursday are SQL practice. SAP study time can cover ERP concepts, business processes, APIs and relevant SAP learning material. As the roadmap advances, SAP learning shifts toward CAP, Integration Suite and Build.

## Suggested two-hour session

- 30–40 minutes: lesson or guided material.
- 60–75 minutes: hands-on exercises.
- 10–20 minutes: summarize what was learned, note questions and commit useful work to GitHub.

Do not spend the full session watching videos. Type and run the code yourself.

## Weekly review

At the end of Sunday, record:
- What topics can I now explain without notes?
- What can I build or query independently?
- What did I struggle with?
- What is the next concrete task?
- Did I update the relevant project README or learning notes?
